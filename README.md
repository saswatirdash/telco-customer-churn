# 📊 Telco Customer Churn Analysis

## 📌 Project Overview

This project analyzes **Telco customer churn** to understand customer behavior, identify factors associated with churn, and present key insights through an interactive **Power BI dashboard**.

## 🎯 Objectives

* Analyze customer churn patterns
* Identify factors affecting customer retention
* Compare churn across different customer segments
* Analyze contract types, payment methods, tenure, and charges
* Create an interactive dashboard for easy data exploration

## 🛠️ Tools & Technologies

* **Power BI** – Data cleaning, transformation & visualization
* **Power Query** – Data preprocessing
* **DAX** – Measures and KPI calculations
* **Excel/CSV** – Dataset

## 📊 Dashboard Highlights

* Total Customers
* Churned Customers
* Churn Rate
* Monthly Charges
* Tenure Analysis
* Churn by Contract Type
* Churn by Payment Method
* Customer Demographics
* Interactive slicers and filters

## 🔍 Key Analysis

The dashboard helps explore how churn varies based on:

* Contract type
* Customer tenure
* Monthly charges
* Payment method
* Internet service
* Senior citizen status
* Partner and dependent status
